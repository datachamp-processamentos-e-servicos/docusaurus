## Cadastrar Nova Unidade

Acesse:

**Cadastros → Itens → Unidades de Medida**

1. Clique em **+ Novo** para cadastrar uma unidade ou selecione uma unidade existente na lista para editá-la.
2. Preencha as informações necessárias;
3. Clique em **Salvar** para concluir o cadastro.

## Informações da Unidade

Nesta seção são definidas as informações utilizadas para identificar e configurar a unidade de medida dos itens cadastrados no sistema.

Conforme a necessidade da empresa, podem ser informadas informações como:

- Nome;
- Abreviatura;
- Tipo;
- Unidade P/FCI;
- Situação;
- Quantidade de Decimais;
- Largura;
- Altura;
- Profundidade;
- Cubagem;
- Peso;
- Observação.

O campo **Situação** permite selecionar o status : Ativo ou inativo.


Essas informações auxiliam na padronização das unidades de medida e podem ser utilizadas em processos comerciais, fiscais e logísticos.

## Configuração de Cubagem 

**Como configurar**

Acesse:

**Cadastros → Itens → Unidades de Medida**

A cubagem e as dimensões dos produtos devem ser configuradas na **Unidade de Medida**.

Para cada tamanho de embalagem utilizado, cadastre uma **Caixa Master** diferente, informando suas respectivas dimensões, cubagem e peso.

---

**Exemplo de cadastro**

```text
Nome: CAIXA DE PAPELAO 160 X 140 X 120
Abreviatura: CX35
Tipo: Caixa Master
Unidade P/FCI: 99 - Outras unidades
Decimais: 00
Largura: 14,00
Altura: 12,00
Profundidade: 16,00
Cubagem: 0,0027
Peso: conforme o peso correspondente
```

:::note[Importante]
Os valores acima são apenas um exemplo de uma configuração já utilizada no Sentus.

As **dimensões, cubagem e peso** devem ser preenchidos conforme as características reais de cada caixa utilizada pela empresa.
:::

Cadastre uma **Caixa Master para cada tamanho de caixa utilizado**. Após informar as dimensões, cubagem e peso correspondentes, salve o cadastro.

---

**Finalizando**

Após revisar as informações, clique em **Salvar** para concluir o cadastro da unidade.
