# Parâmetros

## Configurar Regras e Parâmetros

Acesse:

**Cadastros → Demais Cadastros → Parâmetros**

1. Selecione o parâmetro desejado na lista.
2. Informe ou altere o valor conforme a necessidade.
3. Clique em **Salvar** para aplicar as alterações.

## Parâmetros

Nesta seção são exibidos os parâmetros disponíveis para configuração das funcionalidades do sistema.

Cada parâmetro possui um tipo, um valor configurável e uma ação correspondente.

Caso necessário, utilize a opção **Sincronização**, disponível no menu **Opções**, para atualizar as informações relacionadas aos parâmetros.

As alterações realizadas nessa tela podem impactar o funcionamento de determinadas rotinas do sistema.

---

## Alteração de Alíquota do Simples Nacional

Acesse:

**Cadastros → Demais Cadastros → Parâmetros**

Para alterar a alíquota, siga o passo a passo:

1. Após abrir a aba **Parâmetros**, ao lado do campo **Atual**, localize a área **Nova**.
2. Informe a nova alíquota nessa área.
3. Após realizar a alteração, clique em **Salvar**.
4. A nova alíquota será aplicada.


:::warning[Atenção]
- Se for a sua primeira vez acrescentando a alíquota de crédito do Simples Nacional, entre em contato com o Suporte. Somente o Suporte consegue realizar essa implementação;
- Esta aba será exibida somente se a sua empresa estiver enquadrada no Simples Nacional;
- Se estiver enquadrada no Simples Nacional e a aba não aparecer, entre em contato com o Suporte.
:::

---

**Finalizando**

Após revisar as informações, clique em **Salvar** para concluir as alterações dos parâmetros.
