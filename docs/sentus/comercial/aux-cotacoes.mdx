# Cotações 

## Para que serve?

A rotina de **Cotações**, localizada nos auxiliares do módulo Comercial, permite cadastrar e consultar valores de cotação vinculados aos indicadores utilizados no Sentus.

Para acessar, vá até:

**Comercial → Auxiliares → Cotações**

---

## Lista de Cotações

Ao acessar a rotina, o sistema apresenta a **Lista de Cotações de Indicadores**.

Na grade são exibidas as seguintes informações:

- **ID:** identificação do registro;
- **Indicador:** indicador relacionado à cotação;
- **Data:** data da cotação;
- **Valor:** valor informado para o indicador;
- **Ações:** opções disponíveis para o registro.

---

## Adicionar uma nova Cotação

Para cadastrar uma nova cotação de indicador, clique em **+ Novo** na tela **Lista de Cotações de Indicadores**.

Preencha as seguintes informações:

- **Indicador:** selecione o indicador ao qual a cotação será vinculada.
- **Data:** informe a data correspondente à cotação.
- **Valor:** informe o valor do indicador para a data selecionada.

Para sair sem registrar as informações, clique em **Cancelar**.

---

**Finalizando**

Após preencher as informações, clique em **Salvar** para concluir o cadastro.
