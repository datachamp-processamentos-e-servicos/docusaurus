# Indicadores

## Para que serve?

A rotina de **Indicadores**, localizada nos auxiliares do módulo Comercial, permite cadastrar e gerenciar os indicadores utilizados no Sentus.

Os indicadores podem ser vinculados às **Cotações de Indicadores**, permitindo posteriormente registrar valores para determinadas datas.

Para acessar, vá até:

**Comercial → Auxiliares → Indicadores**

---

## Lista de Indicadores

Ao acessar a rotina, o sistema apresenta a **Lista de Indicadores**.

Na grade são exibidas as seguintes informações:

- **ID:** identificação do indicador;
- **Nome:** nome do indicador cadastrado;
- **Situação:** situação atual do indicador;
- **Ações:** opções disponíveis para o registro.

---

## Adicionar um novo Indicador

Para cadastrar um novo indicador, clique em **+ Novo** na tela **Lista de Indicadores**.

Preencha as seguintes informações:

- **Nome:** informe o nome que identificará o indicador.
- **Situação:** selecione a situação correspondente ao indicador.

As situações disponíveis são:

- **Ativo**
- **Restrito**
- **Bloqueado**
- **Removido**
- **Inativo**

Para sair sem registrar as informações, clique em **Cancelar**.

---

**Finalizando**

Após preencher as informações, clique em **Salvar** para concluir o cadastro do indicador.
