## Cadastrar Nova Informação Complementar

Acesse:

**Tributos → Auxiliares → Informações Complementares**

1. Clique em **+ Novo** para cadastrar uma informação complementar ou clique em um registro existente para editá-lo;
2. Preencha as informações do cadastro;
3. Clique em **Salvar** para concluir o cadastro.

## Informações Complementares

Nesta seção são definidos os dados utilizados para compor automaticamente as mensagens fiscais dos documentos emitidos pelo sistema.

Preencha as principais informações, como:

- Nome;
- Tipo;
- Tributo;
- Situação;
- Mensagem para Informações Complementares;
- Mensagem para Informações Adicionais do Fisco;
- Mensagem Fiscal para EFD.

Essas informações poderão ser utilizadas conforme a configuração da operação tributária e da tributação aplicada.

---

## Legenda

Nesta seção são apresentadas as **tags disponíveis** que podem ser utilizadas na composição das mensagens fiscais.

As tags permitem que o sistema substitua automaticamente informações, como:

- Base de cálculo;
- Alíquota;
- Valor do imposto;
- Valor unitário;
- Documentos referenciados;
- Chave dos documentos;
- Mês e ano de emissão;
- Cadastro vitícola;
- Informações de cubagem;
- Outras informações disponíveis conforme o tributo.

Utilize essas tags quando for necessário montar mensagens fiscais dinâmicas.

---

**Finalizando**

Após revisar as informações, clique em **Salvar** para concluir o cadastro da informação complementar.
