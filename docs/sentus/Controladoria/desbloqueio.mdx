## Para que serve?

A rotina de **Desbloqueio** permite consultar registros financeiros disponíveis para o processo de desbloqueio no Sentus.

Para acessar, vá até:

**Controladoria → Desbloqueio**

---

## Lista de Registros

Ao acessar a rotina, o sistema apresenta a tela **Financeiro - Desbloquear**, contendo os registros disponíveis para consulta.

Na grade são apresentadas as seguintes informações:

- **Tipo:** identifica o tipo do registro;
- **Número:** número ou descrição do registro;
- **Emissão:** data de emissão;
- **Valor:** valor do registro;
- **Faturado:** valor faturado;
- **Participante:** participante relacionado ao registro;
- **Observação:** informações adicionais relacionadas ao lançamento;
- **Ações:** apresenta as ações disponíveis para o registro.

Também é possível selecionar registros utilizando a caixa de seleção localizada no início de cada linha.

---

## Localizar um Registro

Utilize o campo **Pesquisar** para localizar o registro desejado.

Após informar os dados da pesquisa, clique no botão de **confirmação (✓)** ou em **Pesquisar** para realizar a consulta.

---

## Desbloquear um Registro

Para desbloquear um registro:

1. Localize o registro desejado na lista.
2. Marque a caixa de seleção correspondente ao registro.
3. Clique em **Opções**, no canto superior direito.
4. Selecione **Desbloquear**.

Após selecionar **Desbloquear**, o registro é desbloqueado imediatamente e deixa de aparecer na lista.

Também é possível realizar o desbloqueio utilizando o ícone de **Cadeado** disponível na coluna **Ações**.

:::warning[Atenção]
Antes de realizar o desbloqueio, confira se o registro selecionado é o correto, pois a operação é executada imediatamente.
:::

---

## Totalizar Registros

A opção **Totalizar** permite consultar o total dos registros selecionados.

Para utilizar:

1. Selecione um ou mais registros na lista.
2. Clique em **Opções**.
3. Selecione **Totalizar**.

---

**Finalizando**

Após selecionar e desbloquear os registros desejados, revise a lista para confirmar que os itens foram removidos e que o processo foi concluído.
