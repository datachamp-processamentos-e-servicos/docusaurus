## Conciliação bancária

A tela de **Conciliação** está disponível em **Financeiro > Cobrança Bancária > Conciliação**.

Conciliação do sistema busca e faz a conexão entre o sistema e o Banco trazendo os pagamentos e as informações utilizáveis. 

Na parte superior da tela, estão disponíveis os recursos **Pesquisar**, **Opções**, **Buscar Da API** e **Conciliação**.

## Filtros aplicados

A área **Filtros Aplicados** apresenta os filtros utilizados na consulta, incluindo o período de **Emissão**.

## Resultados

Os registros encontrados são apresentados em uma tabela com as seguintes informações:

- **ID**
- **Data**
- **Nome do Arquivo**
- **Portador**
- **Ações**

## Buscar via API

Ao selecionar **Buscar Da API**, é exibida a janela **Via API**.

Nessa janela, estão disponíveis os seguintes campos:

- **Portador**: utilizado para selecionar o portador.
- **De**: informa a data inicial do período.
- **Até**: informa a data final do período.

## Enviar arquivo para conciliação

Ao selecionar **Conciliação**, é exibida a janela **Selecione o Arquivo Desejado.**.

Para selecionar e enviar o arquivo:

1. Clique em **Escolher arquivo**.
2. Selecione o arquivo desejado.
3. Clique em **Upload**.

Para sair da janela sem realizar o envio, clique em **Fechar**.
