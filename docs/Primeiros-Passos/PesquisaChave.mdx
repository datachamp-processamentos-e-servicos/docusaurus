# Pesquisa por Palavras-chave Ⓧ

:::note[Importante]
Esta forma de pesquisa pode ser utilizada em praticamente todas as telas de pesquisa do **Sentus**, como produtos, clientes, fornecedores, participantes, transportadores, entre outros.
:::

---

**Como pesquisar**

Ao pesquisar um registro, informar apenas o nome completo pode não retornar resultados, pois o cadastro pode conter outras descrições, códigos ou informações complementares.

Para ampliar a pesquisa, utilize o caractere **%** antes de cada palavra que deseja localizar.

---

**Exemplo**

Ao pesquisar apenas:

```text
Rolo Hardox
```

O sistema poderá **não localizar nenhum registro**.

Pesquisando da seguinte forma:

```text
%Rolo %Hardox
```

O sistema retornará todos os registros que contenham as palavras **Rolo** e **Hardox** na descrição, mesmo que existam outras informações entre elas.

---

:::tip[Dica]
Sempre que tiver dificuldade para localizar um cadastro, utilize o caractere **%** antes das palavras-chave. Essa pesquisa funciona na maioria das consultas do **Sentus**, facilitando a localização de registros.
:::
