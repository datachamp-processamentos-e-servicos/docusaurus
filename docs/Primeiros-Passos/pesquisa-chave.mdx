# Pesquisa por Palavras-chave Ⓧ

:::note[Importante]

Ao pesquisar um item ou produto, informar apenas o nome completo pode não retornar resultados, pois o cadastro pode conter outras descrições, medidas ou características.

:::

## Como pesquisar um produto

Para localizar um item de forma mais ampla, utilize o caractere **%** como curinga na pesquisa.

### Exemplo

Ao pesquisar apenas:

```text
Rolo Hardox
```

O sistema poderá **não localizar nenhum registro**.

Pesquisando da seguinte forma:

```text
%Rolo %Hardox
```

O sistema retornará **todos os itens cadastrados** que contenham as palavras **Rolo** e **Hardox** na descrição, facilitando a localização do produto.

:::tip[Dica]

Utilize o caractere **%** antes de cada palavra que deseja pesquisar para ampliar os resultados da busca.

:::
